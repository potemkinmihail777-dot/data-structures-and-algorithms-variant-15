# Структуры и алгоритмы обработки данных — вариант 15

Учебный комплект из **8 лабораторных первого семестра**, Python 3.10+, **seed = 30 + 15 = 45**. Основание: [репозиторий курса МТУСИ](https://github.com/mel0d1an/data-structures-and-algorithms), версия `6369770ffb455f34cbb0020133638d0961fc34ed`.

| Работа | Тема | Материалы |
| --- | --- | --- |
| [ЛР 1](labs/lab01/README.md) | Анализ сложности | Сумма, максимум, пары, бинарная степень |
| [ЛР 2](labs/lab02/README.md) | Рекурсия и линейные структуры | Фибоначчи, Ханой, массив, стек, дек |
| [ЛР 3](labs/lab03/README.md) | Простые сортировки и QuickSort | Счётчики, стабильность, разбиения |
| [ЛР 4](labs/lab04/README.md) | Эффективные сортировки | Merge, Counting, Radix, Heap |
| [ЛР 5](labs/lab05/README.md) | Бинарное дерево поиска | Вставка, поиск, удаление, обходы |
| [ЛР 6](labs/lab06/README.md) | Поиск в массиве | Линейный, бинарный, интерполяционный |
| [ЛР 7](labs/lab07/README.md) | Поиск подстрок | Наивный, КМП, Рабин–Карп, Бойер–Мур |
| [ЛР 8](labs/lab08/README.md) | Хеш-таблица | Цепочки, rehash, коэффициент загрузки |

В каждой папке: `algorithms.py` — реализация, `test_lab.py` — проверки, `experiment.py` — воспроизводимый опыт, `notes.md` — понятный конспект и вопросы защиты, `report.md` — фактические результаты, `results/` — CSV/JSON и графики. Дополнительные ДЗ 1–4 и зачёт не являются лабораторными и в этот комплект не входят.

## Быстрый запуск

Из корня репозитория:

```text
python -m venv .venv
```

Windows PowerShell:

```text
.venv\Scripts\Activate.ps1
```

Linux/macOS:

```text
source .venv/bin/activate
```

Затем:

```text
python -m pip install -r requirements.txt
python scripts/generate_data.py --variant 15 --only arrays
python scripts/generate_data.py --variant 15 --only texts
python scripts/generate_data.py --variant 15 --only pairs
python -m pytest -q
python -m labs.lab01.experiment --variant 15
```

Для другой лабораторной замените `lab01` на `lab02`…`lab08`. Для всего комплекта:

```text
python -m scripts.run_all --variant 15
```

Полный эксперимент занимает заметное время: в ЛР 1 проверяются сотни миллионов пар, в ЛР 7 обрабатываются миллионные тексты. Повторять все измерения перед каждым чтением отчёта не требуется: готовые результаты сохранены. Данные генерируются локально и не загружаются в Git; их контрольные суммы записаны в `results/environment.json` каждой работы.

## Как готовиться к защите

1. Прочитать конспект соответствующей работы и пройти пример вручную.
2. Запустить тесты: `python -m pytest labs/lab01 -q`.
3. Найти в коде инвариант, базовый случай и обработку пустого входа.
4. Открыть отчёт, графики и исходные пять повторов замеров.
5. Ответить на вопросы в конце конспекта своими словами.

Решения подготовлены с использованием генеративного ИИ и проверены автоматическими тестами и реальными экспериментами. Описание роли ИИ и ограничений проверки: [AI_USAGE.md](AI_USAGE.md). Источник заданий, заимствованные материалы и лицензия: [SOURCES.md](SOURCES.md).

## Методика замеров

Один прогрев, пять измерений `time.perf_counter`, медиана; ввод, генерация и подготовка свежих копий вне таймера. Последовательное выполнение лабораторных. Результаты относятся к указанному в паспорте компьютеру и версиям библиотек. Фоновые процессы и питание не контролировались; это учебные измерения на рабочем компьютере. Особенности сравнения реализаций объяснены в каждом отчёте.

Проверка оформления: Black. Проверка локальных ссылок и структуры: `python scripts/check_links.py`. Для повторной сборки PDF/Word предусмотрены `requirements-docs.txt` и `python scripts/build_documents.py --out documentation`.
